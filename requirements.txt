# ⚠️ 只装下面这一个 chromadb，不要再另外安装 chromadb-client！
#    两者共用同一个 chromadb/ 目录，chromadb-client 会写进
#    chromadb/is_thin_client.py，使完整的 chromadb 误判自己是瘦客户端，
#    PersistentClient 直接抛 "Chroma is running in http-only client mode"，
#    整个后端在 import 阶段就会崩掉、根本起不来。
#    一旦装错了，删掉 venv/Lib/site-packages/chromadb/is_thin_client.py 即可恢复。
